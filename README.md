# 工具集

本项目是一个随手创建的工具集。

## 工具列表

- [AppImage Manager](./appimage%20manager/)：用于在 Linux 桌面环境中安装、更新、查询和卸载 AppImage。
- [KOReader Install](./koreader%20install/)：用于在已安装 KPM 的越狱 Kindle 上，从本地 `.kpkg` 软件包安装 KOReader。
- [Chromium uBlock Fix](./chromium-ublock-fix/)：用于在 Linux x86_64 上为 Chromium 构建经过功能验证的 MV2 兼容副本，升级后继续使用完整版 uBlock Origin；附带修复器、扩展和迁移说明。
